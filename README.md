# Resume Builder

Build a resume with a live preview and download it as PDF.

## Features

- Form for personal details, summary, skills, experience, projects and education
- Live preview that updates as you type
- Two templates: Canada (ATS format) and Switzerland (EU CV)
- Download as PDF using the browser print option
- Data is saved in the browser (localStorage)
- Responsive layout with Edit and Preview tabs on mobile

## Built With

HTML, CSS, JavaScript (no libraries)

## Live Demo

 https://komalpatel28.github.io/Resume-Builder/

## How to Run

1. Download or clone this repository
2. Open `index.html` in your browser
